# Sample Report Documentation

This document describes the format of the Markdown report generated by `report_generator.py`.

See `reports/sample_report.md` for an actual generated example.

## Report Structure

```markdown
# Telemetry Run Report

Generated: <ISO 8601 UTC timestamp>

## Summary
- Duration: X.XXX s
- Packets received: N
- Estimated packet loss: X.XX%
- Average packet rate: X.XX Hz
- Status: OK | FAULT

## ADC Statistics
- Minimum ADC: X mV
- Maximum ADC: X mV
- Average ADC: X.X mV

## Fault Summary
| Fault | Count |
|-------|-------|
| ADC_OUT_OF_RANGE | N |
| BUTTON_EVENT | N |

## Notes
<free-form notes section>
```

## Generating a Report

From a JSONL log file:
```bash
python -m telemetry_client.cli report \
    --input data/sample_logs/sample_run.jsonl \
    --output reports/run_report.md
```

From a Python script:
```python
from telemetry_client import generate_report
from telemetry_client.packet_parser import parse_packet

packets = []
with open("data/sample_logs/sample_run.jsonl") as f:
    for line in f:
        try:
            pkt = parse_packet(line)
            if pkt["type"] == "telemetry":
                packets.append(pkt)
        except ValueError:
            pass

generate_report(packets, "reports/run_report.md")
```
